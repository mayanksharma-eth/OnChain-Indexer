# Demo fixture — not part of the product

This directory exists only to drive a real, reproducible end-to-end run of the indexer/API
against real onchain events, instead of the mocked chain used by `tests/integration`. Nothing
under `demo/` is imported by `apps/` or `packages/`.

- `contracts/src/Intent.sol` — a minimal contract emitting the exact `IntentCreated` /
  `IntentCancelled` / `IntentFilled` signatures decoded by `packages/abi/src/intent.ts`. No
  business logic beyond emitting events — it exists to be indexed, not to be a real protocol.
- `run.sh` — starts a local Anvil chain, deploys the contract, and sends a couple of real
  transactions against it.

`contracts/cache/` and `contracts/out/` are Foundry build output — gitignored, regenerated by
`forge build` (or by `run.sh`, which calls it for you).

## Run it

Requires [Foundry](https://getfoundry.sh) (`anvil`, `forge`, `cast`) installed locally.

```bash
./demo/run.sh
```

Leave that terminal running — it prints the deployed `CONTRACT_ADDRESS` and the exact `.env` /
`pnpm` commands to point the real indexer and API at it, plus `curl` commands to confirm the
events made it all the way through to the HTTP API.
